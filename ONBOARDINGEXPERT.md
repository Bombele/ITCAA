# ONBOARDING – Expert (CI/CD & Certification)

## 🎯 Objectif
Donner aux architectes techniques et responsables institutionnels les outils pour auditer, certifier et déployer l’infrastructure ITCAA.

## ⚙️ CI/CD complet
- **Workflows GitHub Actions** :  
  - `structure-check.yml` : vérification de la structure du projet.  
  - `predeploy_check.yml` : tests avant déploiement.  
  - `deploy.yml` : déploiement automatisé.  
  - `annual_report.yml` : génération de rapports institutionnels.  
- **Makefile & `_install.yml`** : alignement dev/prod, installation automatisée.

## 📜 Certification
- **Protocoles DIH** : distinction, proportionnalité, humanité.  
- **Légitimité institutionnelle** : responsabilité interne, reconnaissance communautaire.  
- **Normes internes** : codes de conduite, chartes institutionnelles.  

## 🤖 Audit IA
- Vérification automatique : lint, typecheck, tests.  
- Validation des dépendances IA.  
- Index FAISS et prédiction supervisée pour certification hors ligne.  

## 📓 Traçabilité
Chaque correction technique est documentée dans la Bitácora pour assurer transparence et onboarding international.  

## 🛠️ Exemples concrets
- Exécuter un pipeline CI/CD pour déployer automatiquement.  
- Générer un rapport annuel institutionnel via GitHub Actions.  
- Auditer un module IA avec `QUALITY_GUIDE.md`.
